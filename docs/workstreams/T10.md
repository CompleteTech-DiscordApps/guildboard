# T10: GoDaddy Infrastructure & CI/CD

Owner expertise: Platform Engineering. No individual assignment implied.

## Research question

Verify GoDaddy Linux VPS sizing, supported Linux images, resource/storage limits and networking; keep managed Node hosting optional and unverified.

## Required contract

Specify mandatory Linux VPS topology, Nginx HTTPS/WSS, database/storage/secret boundaries and staged deployment/rollback procedure.

## Capability scope

### VPS foundation

- **GoDaddy Linux VPS sizing and provisioning**: Select supported Linux and current Node LTS after compatibility review; size CPU/RAM/disk from load goals; document provisioning, SSH hardening, firewall and patch ownership without claiming provisioned resources.

- **MySQL/MariaDB, persistent storage and secrets**: Configure private database listener, least-privilege app credentials, persistent asset volumes and backup paths; use runtime secret files/environment outside source and images; test restart persistence.

### Production networking

- **Nginx HTTPS, TLS renewal and WSS proxy**: Configure trusted DNS hostname, HTTPS redirect, TLS renewal and WebSocket upgrade/timeouts; set secure headers and request limits; verify actual certificate chain and WSS from outside VPS.

- **Discord Activity mappings and DNS acceptance**: Map Developer Portal routes to production HTTPS/WSS; verify proxy behavior, iframe CSP/origins and supported clients on actual GoDaddy deployment; record evidence and unresolved platform limitations.

### Environment delivery

- **Development, staging and production services**: Define reproducible Docker Compose or systemd service management with separate env, database and secrets; configure health/readiness, resource limits, restart and graceful shutdown.

- **CI, versioned builds and SSH deployment**: Run lint/type/tests/security before versioned artifacts; deploy via protected environment with host-key verification and least privilege; prevent untrusted PR secrets and concurrent deployment races.

### Safe releases

- **Migrations, health checks and safe rollback**: Apply compatibility-aware migrations with backups and explicit rollback boundaries; verify health before traffic switch; roll back image safely without pretending destructive schema reversal is automatic.

- **GoDaddy production networking verification**: Run external HTTPS/WSS, reconnect, large-message, idle-timeout and renewal tests against real VPS; prove firewall/database isolation and Discord launch; attach timestamped environment evidence.
